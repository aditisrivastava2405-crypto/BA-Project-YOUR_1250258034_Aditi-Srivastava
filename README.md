## Project Overview
This project focuses on descriptive analytics using IBM Cognos Analytics and Microsoft Power BI. It explores retail sales information through reports, tables, visualizations, and summary measures.

## Objectives
- Prepare and analyze retail sales information.
- Create reports using IBM Cognos Analytics.
- Develop visualizations and summary measures using Power BI.
- Identify useful sales patterns and insights.
- Present findings and recommendations in a descriptive report.

## Tools Used
- IBM Cognos Analytics
- Microsoft Power BI
- Microsoft Excel
- GitHub

## Repository Structure
- `report/` – Final descriptive report PDF.
- `screenshots/` – Screenshots of practical work and results.
- `cognos/` – Available Cognos report exports and supporting files.
- `powerbi/` – Power BI report PDF and supporting evidence.
- `data/` – Reserved for source data, if available.

## Practical Work and Limitations
Available Cognos outputs and Power BI visualizations are included in this repository. Some Cognos reports could not be executed because of server errors. These limitations are documented in the submitted report, and unsuccessful outputs are not presented as completed results.

The original dataset could not be exported from Cognos, so it has not been recreated or represented as an original source file.

## Main Deliverable
The final descriptive analytics report is available in the `report/` folder.

## Conclusion
This project demonstrates the use of descriptive analytics tools to summarize retail sales information, present findings visually, and communicate observations and recommendations.
